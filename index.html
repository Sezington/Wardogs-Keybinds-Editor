WarDogs looks like it's running. Close it first, or it may overwrite your changes when it exits.

Every save keeps a backup of the previous file next to it, and the very first one is kept as GameUserSettings.original-backup.ini.

Open GameUserSettings.ini in Notepad, press Ctrl+A, paste, then save. If you download instead, rename the file to exactly GameUserSettings.ini. Turn on file name extensions in Windows so it doesn't stay .ini.txt.

If you open the keybind menu in-game and change something, the game might undo the stacked keys.
